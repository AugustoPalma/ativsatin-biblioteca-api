# API de Gerenciamento de Biblioteca

Trabalho Prático 2 — atividade 1/3: criar e testar uma skill de code review.

API simples em Node.js/Express para gerenciar livros, usuários e empréstimos de uma biblioteca. Usada como base de código para as rodadas de revisão automatizada.

## Rodando localmente

```bash
npm install
npm start
```
